02SQL analysis · MySQL

Tech Layoffs, 2020–2023

I cleaned 2,361 raw layoff records in MySQL, then asked who was hit, when, and how hard. 2022 was the peak, and 2023 reached 78% of 2022's total by early March.

  • Removed duplicates with ROW_NUMBER() in staging tables, so the raw data never changed
  • Standardized company, industry and country names, turned text into real dates, and filled missing industries with a self-join
  • Rolling monthly totals and each year's top five companies with window functions
  • MySQL
  • CTEs
  • Window functions
  • Data cleaning
Code 
-- each year's top five companies by layoffs
WITH company_year AS (
  SELECT company, YEAR(`date`) AS years,
         SUM(total_laid_off) AS total_laid_off
  FROM layoffs_staging2
  GROUP BY company, YEAR(`date`)
)
SELECT *, DENSE_RANK() OVER (
         PARTITION BY years
         ORDER BY total_laid_off DESC) AS ranking
FROM company_year;
